# aw-review-checker-api

An API written in C# (.NET 8) that pulls reviews for Amazon products and analyzes them to determine whether each review was written by a human or generated by AI.

## Features

- **Swagger UI** served at the root URL (`/`)
- Accepts an **Amazon product URL** or bare **ASIN** (product number)
- Scrapes **product information** (title, price, image, average rating) from Amazon
- Scrapes the first page of **customer reviews**
- Sends each review body to **OpenAI** (gpt-4o-mini by default) to score the likelihood of AI generation on a scale of **1 (definitely human) → 10 (definitely AI)**

## Getting Started

### Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- An [OpenAI API key](https://platform.openai.com/api-keys)

### Running locally

```bash
# Clone the repo
git clone https://github.com/ajwagner777/aw-review-checker-api.git
cd aw-review-checker-api

# Copy the example .env file and add your OpenAI API key
cp .env.example .env
# Edit .env and add your OpenAI API key

# Run the API
dotnet run --project src/AW.ReviewChecker.Api
```

Alternatively, set the environment variable directly:
```bash
# Windows PowerShell
$env:OpenAI__ApiKey = "sk-..."

# macOS/Linux
export OpenAI__ApiKey="sk-..."
```

The API will start on `http://localhost:5252` (or as configured). Open your browser to that URL to access the Swagger UI.

**Note:** The `.env` file is automatically loaded by the application. See `.env.example` for available configuration options.

### Running with Docker

```bash
export OPENAI_API_KEY="sk-..."
docker compose up --build
```

The API will be available at `http://localhost:8080`.

## API Endpoint

### `POST /api/ReviewChecker/check`

**Request body**

```json
{
  "productInput": "https://www.amazon.com/dp/B08N5KWB9H"
}
```

`productInput` can be:
- A full Amazon product URL (e.g. `https://www.amazon.com/dp/B08N5KWB9H`)
- A bare ASIN / product number (e.g. `B08N5KWB9H`)

**Response (200 OK)**

```json
{
  "product": {
    "asin": "B08N5KWB9H",
    "title": "Echo Dot (4th Gen)",
    "price": "$49.99",
    "imageUrl": "https://...",
    "averageRating": "4.7 out of 5 stars",
    "totalReviews": "123,456 ratings",
    "productUrl": "https://www.amazon.com/dp/B08N5KWB9H"
  },
  "reviews": [
    {
      "review": {
        "reviewId": "R...",
        "author": "Jane D.",
        "title": "Great product!",
        "body": "I love this product...",
        "rating": "5.0 out of 5 stars",
        "date": "Reviewed in the United States on January 1, 2024",
        "verifiedPurchase": true
      },
      "aiScore": 3,
      "aiReasoning": "The review uses specific personal anecdotes and informal language, suggesting human authorship."
    }
  ],
  "averageAiScore": 3.5
}
```

**Error responses**

| Status | Reason |
|--------|--------|
| `400`  | Invalid or missing `productInput` |
| `502`  | Amazon blocked the request or a network error occurred |

## Configuration

| Key | Description | Default |
|-----|-------------|---------|
| `OpenAI:ApiKey` | Your OpenAI API key (required) | — |
| `OpenAI:Model` | OpenAI model to use | `gpt-4o-mini` |

Configuration can be supplied via `appsettings.json`, environment variables (e.g. `OpenAI__ApiKey`), or user secrets.

> **Note:** Amazon's website uses bot-detection measures. The scraper sends browser-like headers but may occasionally be blocked. If you receive a `502` error, try again after a short delay.
